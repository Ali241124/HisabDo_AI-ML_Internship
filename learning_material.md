1. **What is Artificial Intelligence (AI)?**



Artificial Intelligence (AI) is the branch of computer science that enables machines to perform tasks that usually require human intelligence such as learning, reasoning, problem-solving, understanding language, recognizing images, and making decisions.



**Real-world Example**



Face Unlock on a smartphone.



**2. What is Machine Learning (ML)?**



Machine Learning is a subset of Artificial Intelligence that enables computers to learn from data without being explicitly programmed for every task.



**Real-world Example**



Netflix movie recommendation system.



**3. What is Deep Learning (DL)?**



Deep Learning is a specialized branch of Machine Learning that uses neural networks with multiple layers to learn complex patterns from large datasets.



**Real-world Example**



Face recognition on mobile phones.



**4. What is Generative AI?**



Generative AI is a type of Artificial Intelligence that generates new content including text, images, videos, audio, and programming code.



**Real-world Example**



ChatGPT generating an essay.
