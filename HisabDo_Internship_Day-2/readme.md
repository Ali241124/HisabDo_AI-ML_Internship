**Student Data Analysis using Pandas**



This project demonstrates basic data handling in Python using the Pandas library.



**Features**



\- Create student dataset

\- Convert data into a Pandas DataFrame

\- Display all students

\- Filter students with marks above 70

\- Calculate average marks

\- Find highest and lowest scoring students

\- Display total number of students



**Technologies**



\- Python

\- Pandas



**Run**



python student\_data\_analysis.py
