# HisabDo AI/ML Internship - Day 5

## Student Performance Prediction - Model Comparison

### Objective

Compare two machine learning classification models to predict whether a student will pass or fail.

### Models Used

- Logistic Regression
- Decision Tree Classifier

### Features

- Attendance
- Assignment Score
- Midterm Score

### Target

- Pass = 1
- Fail = 0

### Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

### Visualizations

- Pass vs Fail Distribution
- Logistic Regression Confusion Matrix
- Decision Tree Confusion Matrix
- Accuracy Comparison

### Technologies

- Python
- Pandas
- Matplotlib
- Scikit-learn
